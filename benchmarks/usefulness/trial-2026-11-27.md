# Agent A/B pilot — 2026-11-27

## Design

Four tasks, two isolated Git repositories per task (baseline and guarded), same
agent type and prompts except for the guarded arm requirement:

> Before committing, run `aed check --staged --json`; fix error findings.

Hidden graders were not visible to the agents; they were copied in after each
agent finished. Grading was mechanical, not a human-blind study.

| Task | Requirement |
|---|---|
| subtract | Add `subtract` with tests; preserve `add`. |
| apply | Add `apply(op, a, b)` while preserving `add`. |
| cleanup | Reduce test duplication, add `add`/`subtract` integer validation. |
| migration | Add an audit migration and documentation/test note. |

## Results

| Task | Arm | Hidden success | Escaped hidden failures | Post-hoc guard findings | Agent wall time |
|---|---|---:|---:|---:|---:|
| subtract | baseline | yes | 0 | 0 | 16.5s |
| subtract | guarded | yes | 0 | 0 | 16.7s |
| apply | baseline | yes | 0 | 0 | 23.1s |
| apply | guarded | yes | 0 | 0 | 38.3s |
| cleanup | baseline | yes | 0 | 2 | 14.1s |
| cleanup | guarded | yes | 0 | 0 | 83.0s |
| migration | baseline | yes | 0 | 1 | 11.9s |
| migration | guarded | yes | 0 | 0 | 41.2s |

Both arms: **4/4 hidden success**, **0 escaped hidden failures**.

The baseline cleanup agent collapsed three named tests into a parametrized test;
the hidden behavior tests still passed, but the guard would report:

- removed test functions;
- assertion count decreased.

The guarded cleanup agent preserved the named tests and assertion counts while
adding validation.

The baseline migration agent added no ADR and had a post-hoc `one-way-door`
error. The guarded migration agent added an accepted ADR and ended with no
guard findings.

## `agent_ab.py` output

- success rate: `1.0` in both arms (`delta 0.0`);
- escaped regressions: `0.0` in both arms (`delta 0.0`);
- post-hoc findings per task: `0.75` baseline → `0.0` guarded (`delta -0.75`);
- review minutes: not measured (`0.0` placeholder);
- iterations: commit count (`1.0` per task), not agent tool turns.

Total observed agent wall time was ~65.6s baseline versus ~179.2s guarded;
this is a small, noisy pilot and is not a performance estimate.

## Interpretation

This pilot shows the guard changed agent behavior on the two tasks where policy
risk existed:

- it preserved test inventory during cleanup;
- it forced an ADR for a migration.

It did **not** show a behavioral hidden-test improvement: both arms passed all
hidden tests. With only four easy tasks, there is no statistical or real-world
usefulness claim. A credible evaluation needs:

- 20–40 held-out tasks;
- human-blind grading;
- real review-time measurement;
- task classes where test/API regressions can actually escape;
- multiple agent/model runs per task.

The mutation benchmark and this pilot both remain evidence about the guard's
behavior, not proof of production value.
